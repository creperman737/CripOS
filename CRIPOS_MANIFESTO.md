# CripOS Manifesto

## Why CripOS Exists

CripOS exists to provide a fast, modern and enjoyable desktop
experience built on Debian.

We believe an operating system should help people create,
learn, play and build.

---

## Our Principles

💚 Fast

Every second matters.

💚 Simple

Easy for beginners.
Powerful for experts.

💚 Stable

Reliability is more important than unnecessary features.

💚 Beautiful

A clean desktop improves productivity.

💚 Open

The project belongs to the community.

---

## We Build

✔ Software

✔ Tools

✔ Community

✔ Knowledge

---

## We Don't Chase

❌ Bloat

❌ Unnecessary complexity

❌ Closed ecosystems

---

Never Gives Up.


# 📈 Quality Goals

```
Boot Time

< 15 seconds

RAM Usage

< 700 MB

Startup Apps

< 20

Crash Rate

Very Low

Updates

Simple and Safe
```

# 🏅 Definition of Done

```
A feature is DONE when:

- Code is complete.
- Tests pass.
- Documentation is updated.
- UI follows the design system.
- No known critical bugs remain.
```

# 🚀 Endi haqiqiy yo'nalish

Endi CripOS uchun eng muhim maqsadlar:

1. 🎯 **Crip Center**ni tugatish.
2. 🛒 **Crip Store**ni ishlaydigan qilish.
3. 📁 **Crip Files**ni kundalik foydalanish darajasiga olib chiqish.
4. 📦 **Package Manager**ni ulash.
5. 💿 **Birinchi Alpha ISO**ni chiqarish.

Shu beshta vazifa bajarilgach, CripOS endi "konsept" emas, balki **foydalanuvchi o'rnatib sinab ko'rishi mumkin bo'lgan operatsion tizim** bo'ladi. Bu esa loyiha tarixidagi eng katta bosqich bo'ladi. 💚
