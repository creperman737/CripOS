# CripOS Future

## Vision

CripOS aims to become a complete, open-source operating system that is:

- **Gaming-first** — optimized for Steam, Proton, and Wine
- **Developer-friendly** — built with Python, easy to extend
- **User-focused** — simple, fast, and beautiful
- **Community-driven** — open to contributors worldwide

## Upcoming Features

### Alpha 0.2 — Essential Apps

- **Crip Store** — full application store with categories, search, install/remove
- **Crip Files** — complete file manager with copy/move/rename/delete
- **Crip Monitor** — real-time system monitoring with graphs

### Alpha 0.3 — Advanced Experience

- **Gaming Mode** — one-click optimization for gaming
  - Steam Integration
  - Proton Support
  - Wine Compatibility
  - GameMode Installation
  - MangoHud FPS Overlay
- **AI Assistant** — built-in AI companion
  - Chat interface
  - Voice commands
  - System control
- **Performance Tools**
  - CPU governor management
  - GPU driver optimization
  - Swap/Zram configuration

### Beta 1.0 — Feature Complete

- **Cloud Integration**
  - OneDrive
  - Google Drive
  - Dropbox
- **Advanced Security**
  - Full firewall GUI
  - Automatic updates
  - Secure Boot configuration
- **Developer Tools**
  - VS Code integration
  - Docker support
  - Git workflow

### Stable 1.0 — Production Ready

- **Installer** — polished GUI installer
- **ISO Builder** — one-command ISO creation
- **Documentation** — complete user and developer docs
- **Website** — official CripOS website
- **Community** — forums, Discord, GitHub discussions
