## Development Principles

1. **Modular architecture** — each component is independent and testable
2. **Python-first** — all system components built with Python
3. **Dark theme by default** — consistent GitHub-dark-inspired design
4. **Multi-language** — O'zbek and English support from the start
5. **Test-driven** — every module has automated tests
6. **Documentation** — all features documented in `docs/`
