# CripOS Development Rules

## Mission

Create a modern, fast, stable, and open-source operating system based on Debian.

---

## Principles

- Keep it simple.
- Performance first.
- Security by default.
- User-friendly design.
- Open source.
- Community driven.

---

## Supported Languages

- 🇺🇿 Uzbek
- 🇬🇧 English

More languages may be added in future releases.

---

## Design Philosophy

- Modern UI
- Minimalistic
- Dark Theme First
- Green Accent Color
- Smooth Animations

---

## Development Goals

- Stable System
- Gaming Ready
- Developer Friendly
- AI Integration
- Easy Installation

---

## Project Structure

Each application must be independent.

Examples:

- crip-launcher
- crip-center
- crip-store
- crip-update
- crip-welcome

---

## Code Style

- Clean
- Readable
- Modular
- Documented

---

## Community

Everyone is welcome to contribute through GitHub.

Respect each other.

Build together.
